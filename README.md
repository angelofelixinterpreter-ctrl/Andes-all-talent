# Andes AllTalent Website

Static responsive starter website for Andes AllTalent.

## Pages
Home, For Companies, For Candidates, Our Process, Industries, About Us, Resources, Contact.

## GitHub Pages
Upload the contents of this folder to a GitHub repository. In Settings > Pages, publish from the main branch/root.

## Before launch
The forms are DEMO forms and do not store information. Connect them to a secure backend/CRM before collecting real company or candidate data. Do not expose CVs or personal data in a public folder.
